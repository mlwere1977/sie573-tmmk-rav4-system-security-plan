# Milestone 3: Risk Management Framework Assessment (Week 4)

|---|---|

| 3. Threat modeling & cyber-physical risk register | 5 risks (R-01 to R-05) scored on a 5×5 likelihood/impact matrix and mapped to Purdue layers and real incidents |
| 4. Architecture-specific control strategy | AC-4, SI-7, SR-6, and IR-4 strategies, plus tailored RMF tasks P-14, S-1, I-2, and M-2 |
| 5–6. Roles & RACI | Four engineering roles with RACI across RMF phases and each risk |
| 7. RMF → SSP mapping | How each RMF output feeds each SSP section |
