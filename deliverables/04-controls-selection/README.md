# Milestone 4: Controls Selection (Week 5)

📊 [`Controls_Selection_Team_5.xlsx`](Controls_Selection_Team_5.xlsx)

The working control-selection workbook. Every candidate NIST SP 800-53 Rev. 5 control is shown against the Privacy, Low, Moderate, and High baselines and the SP 800-82r3 OT overlay. For each control the team recorded:

- **Implementation description** specific to the production line
- **Control type:** Common / Hybrid / System-specific
- **Implementation level:** Organizational and/or System
- **Designation:** Tailored or Inherited

The final SSP version ([`../05-system-security-plan/SSP_Controls_Selection_Team_5.xlsx`](../05-system-security-plan/SSP_Controls_Selection_Team_5.xlsx)) drops the Privacy, Low, and High columns, rewrites the descriptions for the SSP, and adds a "Modified for SSP" flag.
